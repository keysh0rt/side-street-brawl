SIDE STREET BRAWL — PWA prototype v0.1

FILES
- index.html: playable fighting game prototype
- manifest.webmanifest: installable PWA metadata
- sw.js: basic offline cache

HOW TO TEST
1. Extract the ZIP.
2. Host the folder on a static HTTPS host (for example GitHub Pages, Netlify, or Cloudflare Pages).
3. Open the HTTPS URL in Safari on iPhone.
4. Use Share → Add to Home Screen.
5. For best layout, rotate to landscape.

CONTROLS
- Direction pad: move / reposition
- BLOCK: reduce incoming damage
- PUNCH / KICK: basic attacks
- SPECIAL: usable when the meter is full
- Win by reducing the CPU fighter's health to zero before the timer ends.

This is an early playable prototype, not a finished commercial game. Art is procedurally drawn and intentionally original; there are no external assets or libraries. Multiplayer, persistent progression, sound, character select, and richer animation are not implemented yet.
